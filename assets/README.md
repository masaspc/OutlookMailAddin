# アイコンファイル

このディレクトリには、Outlookアドインのアイコンファイルを配置してください。

## 必要なファイル

以下のPNG形式のアイコンファイルが必要です:

- `icon-16.png` - 16x16ピクセル
- `icon-32.png` - 32x32ピクセル
- `icon-64.png` - 64x64ピクセル
- `icon-80.png` - 80x80ピクセル

## アイコンのデザイン

- シンプルで分かりやすいデザイン
- 背景は透過または白
- メール送信防止を連想させるアイコン（例: 盾、チェックマーク、封筒など）

## 作成方法

1. デザインツール（Figma, Adobe Illustrator, Inkscapeなど）でアイコンを作成
2. 各サイズにエクスポート
3. このディレクトリに配置

## 注意事項

- manifest.xmlで参照されているため、ファイル名は正確に一致する必要があります
- PNG形式である必要があります
- 透過背景を推奨します
